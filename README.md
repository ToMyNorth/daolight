# 🏮 Dao Light — Ancient Eastern Wisdom, Powered by AI

**Discover I Ching divination, AI Tarot readings, daily horoscopes, and Five Elements personality tests. 100% free.**

👉 **[daolight.one](https://daolight.one)**

![Dao Light](https://daolight.one/og-default.png)

## ✨ Features

- **I Ching Divination** — Traditional hexagram readings with AI-powered interpretations
- **AI Tarot** — Intelligent tarot card readings with personalized insights
- **Daily Horoscope** — Zodiac-based daily, weekly, and monthly forecasts
- **Five Elements** — Personality test based on Wu Xing (Wood, Fire, Earth, Metal, Water)
- **Blog** — Articles on Eastern philosophy, mindfulness, and spiritual wellness
- **PWA Support** — Installable, works offline on mobile devices
- **Zero Signup** — No account required, completely free

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4
- **AI**: Vercel AI SDK (OpenAI)
- **Animation**: Framer Motion
- **Language**: TypeScript
- **Deployment**: Vercel

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/ToMyNorth/daolight.git

# Install dependencies
cd daolight
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
